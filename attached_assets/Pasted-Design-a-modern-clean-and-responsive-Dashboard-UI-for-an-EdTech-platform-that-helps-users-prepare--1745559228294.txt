Design a modern, clean, and responsive Dashboard UI for an EdTech platform that helps users prepare for cloud certifications. It should include a Daily Streak Challenge, Recent Activity, Recommended Tests, and Learning Accelerators.

🧱 Layout Requirements
📌 Left Sidebar
Logo

Navigation:

Dashboard (active)

Test Library

Test History

Leaderboard

Resources

AI ChatBot

📌 Header
Welcome text: Welcome back, {user_name}

Continue Learning button

Profile avatar (with dropdown)

Notifications

📌 Daily Streak Challenge Card
Streak status: {day_count} Day(s)

Question of the Day text

Take Question Button

📌 Recent Activity
List of past activities (tests taken, flashcards reviewed, AI chat, etc.)

📌 Recommended Practice Tests
List of test types (with status tags like "Recommended", "New", "Practice")

📌 CTA (Bottom Card)
Prompt to take a practice test, ask AI assistant, browse resources

🔗 API Calls & Data Flow
1. ✅ Daily Streak Challenge Section
📲 API: GET /b/user_activity/daily-streak
Purpose: Show current streak count

Response:

json
Copy
Edit
{
  "streak": 3,
  "last_streak_date": "2025-04-24"
}
📲 API: GET /b/user_activity/daily-question
Purpose: Show “Question of the Day”

Response:

json
Copy
Edit
{
  "question": {
    "id": "dq-123",
    "question_text": "What is the default VPC in GCP?",
    "options": ["A", "B", "C", "D"]
  },
  "user_attempted": false
}

API: POST /b/user_activity/daily-question/submit

json

🧪 Button → Action Mapping
UI Button	API	Action
Take Question	POST /b/user_activity/daily-question/submit	Submits the selected option
View History	(Route + optional API)	Navigate to /test-history
Continue Learning	Frontend route (e.g. /test/start/:test_id)	Starts a test
Recommended Test Card Click	POST /b/user_activity/activities (optional)	Log and redirect to start
Take Practice Test (CTA)	Frontend route	Navigate to test library
