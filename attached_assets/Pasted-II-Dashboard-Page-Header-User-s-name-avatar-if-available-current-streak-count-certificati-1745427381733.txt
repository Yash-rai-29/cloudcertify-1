II. Dashboard Page:

Header: User's name, avatar (if available), current streak count, certification target. Buttons for "Start Practice Test" and "View Profile".

Daily Streak Challenge: Displays the current day of the streak, a progress bar, the daily question (multiple-choice), "Take Quiz" button (changes to "View Results" after submission), and feedback (correct/incorrect, explanation).

Learning Progress: Visual representation of key metrics (tests taken, questions answered, average score, study time) using charts or graphs.

Recent Activity: Displays the last 5 activities (with icons) including descriptions and timestamps. Implement infinite scrolling or "Load More" functionality.

Recommended Tests: Presents up to 4 recommended tests with titles, categories, difficulty levels (visual indicators), popularity scores, and "Start Test" buttons.

Quick Actions: Buttons for "Take Practice Test," "Ask AI Assistant," and "Browse Resources."

III. Profile Page:

User Information: Profile picture (with update option), editable name, email, and certification target. Displays account creation date and last login.

Subscription Details: Current subscription tier, status, renewal date, and an upgrade option (if applicable).

Preferences: Toggle switches for notifications and reminders, theme selection, daily study goal setting.

Achievements: Displays earned badges or certificates, longest streak, and total study hours.

Activity Calendar: A heatmap visualizing daily activity levels, highlighting streak days.

Completed Modules & Saved Resources: Lists completed modules and saved resources (links or document previews).
